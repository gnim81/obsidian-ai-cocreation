# obsidian-ai-cocreation

> An Obsidian vault template for safe AI co-writing — with **enforced permission boundaries**, **explicit human-AI division of labor**, and **auditable iteration**.

[中文文档](README.md) · MIT License

## The problem

Connecting AI agents to your knowledge base for writing hits three walls:

1. **Afraid to grant write access** — one careless write can corrupt your raw sources, long-term notes, or finalized drafts.
2. **Re-explaining everything, every session** — context, audience, voice, taboos: gone the moment a session ends.
3. **No provenance** — which parts did the AI write? No way to audit after the fact.

## What this template does

**Enforced boundaries** (not prompt conventions):

| Layer | Mechanism | Enforced by |
|---|---|---|
| L1 | MCP vault-root pinned to `03-Projects/` (rw instance) | MCP server |
| L2 | `.claude/settings.json` deny rules (sources, finals, areas, governance) | Claude Code family tools |
| L3 | Optional Vault Operator for in-Obsidian AI plugins | Obsidian plugin |
| L4 | `human_locked: true` field lock | Constitution (CLAUDE.md) |

Honest scoping included: L3's shadow snapshots do **not** capture direct writes from external tools (empirically tested) — for the external path, git commits (one per co-writing round) are the real safety net.

**Three-layer content model**: `04-Resources/clippings/` (third-party originals) / `02-Areas/` (your own judgments, human-written only) / `03-Projects/*/10-source/` (per-project source material). Projects produce *works*, clippings store *others' texts*, areas hold *your conclusions*.

**Project zones with AI permissions**: `10-source` read-only → `20-notes` writable → `30-drafts` writable (v1/v2 never overwritten, untouched copies in `_baseline/` for human-AI contribution diffing) → `40-review` / `50-final` / `60-published` write-forbidden.

**Operations included**: 14 slash commands in 5 functional groups (`/intake/`, `/produce/`, `/knowledge/`, `/quality/`, `/query/`) + 3 deterministic bash scripts for mechanical operations (zero-hallucination, zero-token, runnable without an AI session). Plus a status state machine, AI participation labels (`authored_by` / `ai_level`), 3 Bases boards, and a full Chinese operating manual ([使用指南.md](使用指南.md)).

## Quick start

```bash
git clone https://github.com/<you>/obsidian-ai-cocreation.git my-vault
cd my-vault
bash init-vault.sh              # optional: --areas "Writing,Coding,Investing"
```

Then open `my-vault` in Obsidian (trust plugins, enable the core **Templates** plugin), and launch your AI CLI (`claude`, Codex, etc.) at the vault root — approve the two MCP servers.

- **Primary method: external AI CLI + MCP** (Claude Code / Codex CLI / Cursor). In-Obsidian AI plugins (Claudian) are optional enhancements.
- Linux/macOS: overwrite `.mcp.json` with `.mcp.linux.json` (paths are generated by `init-vault.sh`).
- No community plugins are required.
